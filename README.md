# 📊 SubTrack

A sleek, minimalist, and dark-themed web application designed to track and manage your digital subscriptions effortlessly. Built with clean, vanilla front-end technologies.

---

## 🚀 Features

*   **Sleek Dark Mode:** A modern, eyes-friendly Cyberpunk/Dark minimalist interface.
*   **Subscription Management:** Easily add, edit, and delete your active subscriptions.
*   **Budget Tracking:** Keep an eye on your total monthly and yearly expenses in real-time.
*   **Theme Switcher:** Seamlessly toggle between dark UI configurations.
*   **Responsive Layout:** Fully optimized for both desktop monitors and mobile screens using advanced CSS Grid and Flexbox layouts.

---

## 🛠️ Tech Stack

*   **HTML5:** Semantic markup for structure.
*   **CSS3:** Custom properties (variables), Flexbox, and CSS Grid for a fully responsive layout.
*   **Vanilla JavaScript:** Clean, asynchronous DOM manipulation and budget calculation logic.

---

## 💻 Setup & Installation

Since this project is built using vanilla technologies, you don't need to install heavy dependencies. 

1. Clone or download the repository.
2. Extract the files if downloaded as a ZIP.
3. Open `index.html` directly in your browser, or use a local development server (like Live Server in VS Code/WebStorm).
